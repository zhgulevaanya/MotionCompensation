# MotionCompensation — Компенсация движения (AR и фильтр Калмана)

Учебное приложение на **C++/CLI (Windows Forms)** для моделирования сигналов движения и сравнения методов их предсказания/фильтрации: **авторегрессии (AR)** и **фильтра Калмана**.

## Возможности

- **Две модели движения:**
  - **Корабль** — качка с плавно меняющейся амплитудой, случайной частотой/фазой и шумовой составляющей
  - **Поезд** — основное колебание + гауссовы импульсы (прохождение вагонов) + шум
- **Настройка разброса амплитуды** ползунком (0–100%)
- **Предсказание по AR-модели** — расчёт коэффициентов методом **Левинсона–Дурбина**, настраиваемый порядок модели
- **Фильтр Калмана** — модель «положение + скорость», настраиваемые параметры шума процесса `Q` и шума измерений `R`
- **Окно оценки ошибки** — график невязки, **СКО** и максимальная ошибка для каждого метода
- Визуальное сравнение реального сигнала и прогноза на графиках

## Технические детали

- Сигналы генерируются детерминированно-случайным образом (статический `Random`) с возможностью сброса модели
- AR: автокорреляция → рекурсия Левинсона–Дурбина → линейное предсказание `x[n] = Σ aⱼ·x[n−j]`
- Калман: матрицы перехода `A`, наблюдения `H`, ковариации `P`, обновление по инновации
- Графики — `System.Windows.Forms.DataVisualization.Charting`

## Сборка

Требуется Visual Studio с поддержкой **C++/CLI** (`.NET Framework`).

## Структура

| Файл | Назначение |
|---|---|
| `MyForm.h` | Объявление формы и полей |
| `MyForm.cpp` | Модели сигналов, AR, Калман, UI-обработчики |
| `main.cpp` | Точка входа |

## Управление

1. Ползунком задать разброс амплитуды
2. **Построить графики** — сгенерировать сигналы корабля и поезда
3. Для каждого сигнала: задать порядок AR / параметры `Q`, `R` Калмана и нажать соответствующую кнопку
4. В отдельном окне появится график ошибки и метрики (СКО, max ошибка)
